# Aether Discord Bot

Русский Discord бот — модерация, AI чат, веб-панель управления

## Особенности
- Система AI чата с поддержкой контекста
- Команды модерации (бан, кик, мут, варны, тикеты)
- Веб-панель управления с аналитикой
- Система автоматического обновления
- Анти-рейд и автомодерация
- Экономика, уровни, розыгрыши
- Тикет-система с AI поддержкой

- `data/` — данные и кэш
- `services/` — дополнительные сервисы
