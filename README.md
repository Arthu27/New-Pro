# Aether (MOEBIUS) — Discord Bot

Русский Discord-бот с AI-функциями, модерацией и веб-панелью управления.

## Возможности

- **AI-чат** с поддержкой контекста (Mistral / OpenRouter / DeepSeek / локальная Ollama)
- **AI-модерация и AI-тикеты** — автоматическая категоризация, анализ тональности, RAG
- **Модерация** — бан, кик, мут, варны, временные наказания, автомод, антирейд
  - **📁 Демки к наказаниям** — `/proof` или параметр «демка» прямо в `/warn` и `/moderate`:
    доказательство перезаливается в канал `#-доказательства`, админ листает канал и видит всё
  - **😶 Тихий мут** — `/ghostmute`: сообщения нарушителя незаметно исчезают, он не в курсе
  - **🚨 Panic-локдаун** — `/panic on`: все каналы под замок одним нажатием, точный откат
  - **🕵️ /snipe** — последнее удалённое/изменённое сообщение; **📌 /stick** — липкие сообщения
  - **⚡ Варн реакцией** — мод ставит ⚠️ на сообщение → автор получает варн; **☢️ /nuke** —
    пересоздание канала; **🧹 /raidcleanup** — кик/бан набежавших; **🧽 /dehoist** — чистка ников;
    **🧾 /case** — досье нарушителя одной PNG-карточкой (варны, демки, заметки, скор)
- **🧹 Автофильтр чата** — запрещённые слова (ловит л33т, повторы букв, раздельный ввод),
  анти-ссылки с whitelist, анти-капс, анти-флуд с таймаутом; авто-варн через систему варнов,
  исключения каналов/ролей, настройка из панели `/autofilter` и командами `/filter`
- **🌐 Публичная статус-страница** — `/status` без логина: онлайн, пинг, аптайм, число серверов
- **💾 Автобэкапы данных** — zip-архив `data/` каждый день по расписанию, ротация старых,
  скачивание из веб-панели; секреты панели в архив не попадают
- **Экономика, уровни, розыгрыши, миниигры**
- **Веб-панель** — аналитика, управление сервером, тикеты, бэкапы, демки, мод-инструменты
- **Музыка, голосовые команды, TTS**
- **Утилиты** — дни рождения, AFK, реакция-роли, приветствия, starboard, опросы
- **Автоматика нового поколения:**
  - **🌙 Ночной режим** — `/ночь`: слоумод и лок каналов по расписанию (напр. 23:00–07:00),
    утром возвращает прежние права точь-в-точь; каналы-исключения, репорты в лог
  - **👶 Анти-альт** — `/антиальт`: ловит свежесозданные аккаунты при входе
    (возраст < N дней), действие на выбор — тревога/кик/бан, белый список
  - **🔒 /lockdown** — аварийное закрытие канала или всего сервера на запись со
    снимком исходных прав; `/unlockdown` возвращает именно их, а не «на глазок»;
    переживает рестарт бота
  - **✍️ Апелляции** — забаненный пишет боту в ЛС `/апелляция`, модераторы решают
    кнопками прямо в карточке (переживают рестарт — persistent views)
  - **📰 Мод-дайджест** — еженедельная сводка: сколько мутов/варнов/банов, кто из
    модераторов активнее, самый горячий день; `/дайджест [дней]` — мгновенно
  - **⏰ Напоминания** — `/напомни "через 10м" текст`, повторы «каждый день …»,
    доставка в канал или ЛС, список и отмена
  - **📊 /recap** — «что я пропустил?»: сводка канала за N часов без AI — топ
    авторов, слова периода, пик активности, самая зареагированная реплика
  - **🏆 Достижения** — ачивки за сообщения/войс/стаж с анонсами в канал,
    `/ачивки` карточка с очками, `/ачивлидеры` — топ сервера
  - **🗂 Шаблоны сервера** — `/шаблон сохранить`: снимок ролей и каналов в
    переносимый JSON; `/шаблон применить` создаёт недостающее, существующее не трогает
  - **👋 Приветствия PRO** — ротируемые шаблоны с переменными `{mention} {server}
    {count}`, карточка с аватаром, ЛС новичку, `/приветствие тест` — превью
  - Настройки всей автоматики редактируются из панели — страница **«Автоматика»**:
    панель и коги читают одну и ту же SQLite-точку, перезапуск не нужен
- **🔢 Считалка** — `/счёт канал`: сервер считает по очереди, сбой — и с 1, рекорд сервера хранится
- **❤ Карма** — `/спасибо @user` или реакция ➕/👍 на чужом сообщении; кулдаун против накруток, `/карматоп`
- **💬 Триггеры** — `/триг добавить слово | ответ`: автоответы по ключевым словам (точное слово или подстрока, кулдаун, счётчик срабатываний)
- **📈 Каналы-счётчики** — `/счётчики добавить #канал Участники: {members}`: живое табло
  в списке каналов (участники/онлайн/каналы/бусты), авто-обновление с уважением к рейт-лимитам
- **⚔ Дуэли** — `/дуэль @user`: вызов с кнопками, честная монетка 50/50, серии побед и топ
- **⭐ Рейтинг стаффа** — `/оценить @мод 1-5`: народный балл модераторов, зачётка с
  комментариями, один голос на человека (переголосование заменяет)
- **Тесты** — `tests/` 50 наборов, 1585 проверок, прогон без токена Discord
- **Бюджет слеш-команд** — в глобальном меню Discord максимум 100 команд;
  `slash_budget.py` держит в меню кураторские ~45 (модерация + ежедневное),
  остальные ~147 команд живут через префикс — ничего не теряется, меню не переполняется
  (`scripts/run_tests.py`)

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # затем заполните TOKEN и ключи
python main.py
```

Бот при старте сам проверяет и доустанавливает недостающие зависимости.

## Запуск через Docker

```bash
docker compose up -d
docker compose logs -f
```

## Веб-панель

Адрес: http://localhost:5001

Логин владельца: `owner`.

Пароль задаётся через `PANEL_PASSWORD` в `.env`. Если он не задан, при первом
запуске генерируется **случайный надёжный пароль** — он выводится в консоль
и сохраняется в `data/panel_credentials.txt` (доступ только у владельца).
После входа попадаешь сразу в панель — без обязательных ритуалов. Пароль
меняется в любой момент по желанию: **Профиль → Сменить пароль**
(txt-подсказка после смены удаляется). Пароль, сменённый через панель,
хранится в `data/panel_credentials.json` — только солёный хэш **scrypt**
(старые SHA-256/plaintext апгрейдятся сами при первом успешном логине).

## Конфигурация

Все настройки — в `.env` (шаблон: `.env.example`):

- `TOKEN` — токен бота из Discord Developer Portal
- `OWNER_ID`, `MAIN_GUILD_ID` — ID владельца и основного сервера
- `MISTRAL_API_KEY` — ключ AI (или альтернативы / локальная Ollama)
- `PORT`, `SECRET_KEY` — веб-панель
- `DISABLE_TUNNEL=1` — отключить Cloudflare Tunnel (в Docker уже задано)

### Режим модулей

- `MOD_ONLY=1` — «только модерация»: грузятся модераторские + системные модули
  (наказания, варны, кейсы, демки, автомод, анти-рейд, верификация, тикеты, журналы).
  Экономика, игры, музыка, AI-чат, ивенты и т.п. выключаются; их данные на диске
  остаются — возврат модулей поднимает всё на место.
- `DISABLED_COGS=music_cog,giveaway` — точечно выключить модули в любом режиме.
- `EXTRA_COGS=economy_cog,level_cog` — вернуть отдельные модули поверх `MOD_ONLY`.
- Логика — в `cogs_policy.py`; применяется при старте. Рантайм без рестарта:
  `!module list` / `!module load <имя>` / `!module unload <имя>` (от владельца).

## Структура

- `main.py` — входная точка бота
- `db.py` — SQLite-слой (`GuildData`/`UserData`), `json_store.py` — JSON-хранилища с кешем чтения
- `cogs_policy.py` — режимы модулей (MOD_ONLY / DISABLED_COGS / EXTRA_COGS)
- `slash_budget.py` — белый список слеш-меню (лимит Discord — 100 команд); что вернуть в меню — добавь имя в `KEEP_SLASH`
- [`cogs/`](cogs/README.md) — 105 модулей команд бота ([каталог](docs/MODULES.md))
- [`services/`](services/README.md) — сервисный слой (форматирование RU-текста, меню панели, AI, бэкапы, SLA, отчёты, плагины)
- [`web/`](web/README.md) — веб-панель (Flask): `app.py`, доменные роуты в `web/routes/`, 93 шаблона
- [`tests/`](tests/README.md) — регрессионный полигон (см. [docs/TESTING.md](docs/TESTING.md))
- [`docs/`](docs/README.md) — документация: каталог модулей, тестирование, архив заметок
- [`scripts/`](scripts/README.md) — регрессия, демо-панель, генератор каталога
- [`config/`](config/README.md) — примеры конфигов
- [`assets/`](assets/README.md) — шрифты, иконки, фоны для карточек
- `data/`, `logs/`, `backups/`, `plugins/` — создаются при запуске (в git не хранятся)

## Полезные команды

- `start.sh` / `start.bat` — запуск на Linux/Windows
- `auto_update.py` — обновление бота
- `scripts/demo_panel.py` — демо-превью панели без Discord (`:8090/demo-login`, поддельный сервер + засеянные логи/демки)
- `scripts/run_tests.py` — вся регрессия одной командой (CI-ready код выхода)
- `scripts/gen_module_docs.py --write` — пересобрать каталог модулей
- `python -m py_compile main.py` — быстрая проверка синтаксиса
