# Панель на личном домене — panel.hakumods.xyz

Как сделать, чтобы панель Aether открывалась по адресу
`https://panel.hakumods.xyz` — без публичного IP и без проброса портов.

Схема: **Cloudflare Tunnel**. Запрос идёт из браузера в ближайший дата-центр
Cloudflare по защищённому HTTPS, а оттуда по шифрованному туннелю — прямо на
твой компьютер к панели (`localhost:5001`). Роутер открывать не нужно, провайдер
(CGNAT/серый IP) не помеха, TLS-сертификат Cloudflare даёт бесплатно и сам.

Сайт `hakumods.xyz` при этом остаётся на хостинге nska — мы только переносим
DNS-зону, контент сайта не трогаем.

---

## Шаг 1. Переносим DNS домена в Cloudflare (один раз, ~10 минут)

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. **Add site** → введи `hakumods.xyz` → выбери план **Free**.
3. Cloudflare просканирует существующие записи — **убедись, что в списке есть
   A-запись `@` → `65.108.15.136`** (это наш сайт!). Если её нет — добавь вручную:
   тип `A`, имя `@`, адрес `65.108.15.136`, облачко **серое** (DNS only).
4. Cloudflare выдаст 2 своих NS-сервера (например `xxxx.ns.cloudflare.com`).
5. Зайди в биллинг hostia (где покупал домен) и **замени NS-серверы** на те,
   что выдал Cloudflare (сейчас там `ns37.nska.net` / `ns38.nska.net`).
6. Жди активацию — от 15 минут до пары часов. Статус виден сразу в Cloudflare:
   как только сайт станет `Active`, двигаемся дальше. Сам сайт hakumods.xyz
   продолжит открываться как раньше — за него отвечает A-запись из шага 3.

## Шаг 2. Запускаем туннель на компьютере (скрипт делает всё сам)

1. В папке бота появился файл **`scripts/setup_panel_tunnel.bat`**
   (обнови папку свежим ZIP: Code → Download ZIP, распакуй с заменой).
2. **Правый клик → «Запуск от имени администратора»** (нужно для автозапуска).
3. Скрипт сам скачает `cloudflared`, откроет браузер для входа в Cloudflare
   (выбери сайт **hakumods.xyz**), создаст туннель `aether-panel`, привяжет
   `panel.hakumods.xyz` и поставит автозапуск службы.
4. В конце увидишь «Туннель запущен».

## Шаг 3. Учим панель жить за доменом

В файле `.env` (рядом с ботом) добавь строку:

```
WEB_BEHIND_PROXY=1
```

Перезапусти бота (`start.bat`). Эта настройка включает ProxyFix — панель
корректно понимает `https://` и хост из заголовков Cloudflare, иначе ломаются
редиректы и часть форм.

## Шаг 4. Пользуемся

- Панель: **https://panel.hakumods.xyz** — логин `owner` + твой пароль
  (из `.env` / `data/panel_credentials.txt`).
- Сайт: **https://hakumods.xyz** — как было, не пострадает.
- С телефона тоже работает.

## Безопасность (важно!)

- Панель видна интернету → пароль владельца должен быть крепким
  (сменить: Профиль → Сменить пароль, либо `PANEL_PASSWORD` в `.env`).
- Ссылку никому не давай: внутри — управление сервером.
- Бонус позже: в Cloudflare Zero Trust → Access можно поставить второй замок
  (вход по одноразовому коду на e-mail) — скажи мне, распишу.

## Если что-то пошло не так

| Симптом | Причина | Лечение |
|---|---|---|
| `panel.hakumods.xyz` не резолвится | NS ещё не переключились | Подождать; проверить статус в Cloudflare |
| Открывается ошибка 502/1033 | Туннель упал или бот выключен | Запустить бота; проверить службу `cloudflared` |
| Логин «выкидывает» после входа | Нет `WEB_BEHIND_PROXY=1` | Добавить в `.env`, перезапустить |
| Сайт hakumods.xyz пропал | Потерялась A-запись | Шаг 1.3: добавить `A @ → 65.108.15.136` |
