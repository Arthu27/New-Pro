# Панель на твоём домене — hakumods.xyz

Как сделать, чтобы **панель Aether открывалась прямо на главном домене**
`https://hakumods.xyz` (а также `www.hakumods.xyz` и `panel.hakumods.xyz`) —
бесплатно, без VPS, без публичного IP и без проброса портов.

Схема: **Cloudflare Tunnel** (именованный, постоянный — адрес не меняется
никогда, туннель сам стартует вместе с Windows). Запрос идёт из браузера в
ближайший дата-центр Cloudflare по защищённому HTTPS (замочек — из коробки),
а оттуда по шифрованному туннелю прямо к панели на твоём ПК (`localhost:5001`).

> ⚠️ Старую страницу-заглушку домена убираем (ты сказал — не нужна). Файлы на
> хостинге nska остаются нетронутыми — если позже захочешь вернуть промо-сайт,
> это делается одной DNS-записью, просто скажи.

---

## Шаг 1. Аккаунт Cloudflare и перенос DNS (≈10 минут потом ожидание)

1. Зайди на https://dash.cloudflare.com и зарегистрируйся (бесплатно).
2. **Add site** → введи `hakumods.xyz` → план **Free** → дальше.
3. Сканирование записей: **A-запись сайта (65.108.15.136) можно удалить** —
   сайт-пустышка больше не нужен, наш скрипт сам создаст нужные записи.
4. Cloudflare покажет **2 своих NS-сервера** (вида `xxxx.ns.cloudflare.com`) —
   сохрани их (сфоткай).
5. В биллинге hostia (где покупал домен): домен `hakumods.xyz` → DNS-серверы →
   **замени** `ns37.nska.net` / `ns38.nska.net` на те два от Cloudflare → сохрани.
6. Жди `Active` в Cloudflare — обычно 15 минут … пара часов (придёт письмо).

## Шаг 2. Скрипт на компьютере (≈5 минут)

1. Обнови папку бота свежим ZIP (Code → Download ZIP → распаковать с заменой).
2. **ПКМ по `scripts\setup_panel_tunnel.bat` → «Запуск от имени администратора»**.
3. Скрипт сам: скачает cloudflared → откроет браузер (нажми **Authorize** на
   hakumods.xyz) → создаст туннель → привяжет все три адреса → поставит
   автозапуск службы Windows.
4. Увидишь «ГОТОВО! Панель живёт на домене».

## Шаг 3. Одна строка в `.env`

Добавь в `.env` (рядом с ботом) и перезапусти `start.bat`:

```
WEB_BEHIND_PROXY=1
```

Это включает ProxyFix — панель корректно понимает `https://` за туннелем,
иначе ломаются редиректы и часть форм.

## Шаг 4. Пользуемся

- **https://hakumods.xyz** — панель (логин `owner` + твой пароль).
- Также открывается: `https://www.hakumods.xyz`, `https://panel.hakumods.xyz`.
- Ссылки **никогда не меняются** — перезагрузка ПК ничего не сбивает,
  туннель поднимается сам.

## Безопасность (важно!)

- Панель теперь видна всему интернету на главном домене → пароль владельца
  должен быть крепким (сменить: Профиль → Сменить пароль, либо `PANEL_PASSWORD`
  в `.env`).
- Ссылку никому не давай: внутри — полное управление сервером.
- Бонус позже: Cloudflare Zero Trust → Access — второй замок на входе
  (код на e-mail). Скажи — распишу.

## Если что-то идёт не так

| Симптом | Причина | Лечение |
|---|---|---|
| Домен не открывается вовсе | NS ещё не переключились | Подождать; статус смотреть в Cloudflare |
| Ошибка 502 / 1033 | Туннель упал или бот выключен | Запустить бота; проверить службу `cloudflared` |
| Логин «выкидывает» после входа | Нет `WEB_BEHIND_PROXY=1` | Добавить в `.env`, перезапустить бота |
| Захотел вернуть сайт-пустышку | — | Удалить CNAME `@` в Cloudflare и вернуть `A @ → 65.108.15.136` |
