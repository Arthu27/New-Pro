# Страницы панели (ядро модерации)

Новая панель с нуля. Старый `web/` и его меню/права **не используются**.

## Для модераторов (mod)

| Страница | URL | Зачем |
| --- | --- | --- |
| **Сегодня** | `/` | KPI за день + последние наказания |
| **Журнал** | `/logs` | Все наказания |
| **Участник** | `/member` | Поиск + история мер |
| **Варны** | `/warns` | Предупреждения |
| **Апелляции** | `/appeals` | Очередь апелляций |
| **Демки** | `/proofs` | Доказательства |
| **Причины** | `/reasons` | Причины + правила |

## Только владелец (owner)

Модераторы этих страниц **не видят**.

| Страница | URL | Зачем |
| --- | --- | --- |
| **Бот** | `/bot` | Онлайн, пинг, гильдии |
| **Модули** | `/modules` | Загруженные коги |
| **Команды** | `/commands` | Обзор slash |
| **Антикраш** | `/anticrash` | Watchdog, алерты, тумблеры |
| **Доступ** | `/access` | Кому выдан вход (только role=mod) |

## Вход

| Страница | URL |
| --- | --- |
| **Вход** | `/login` |

`PANEL_USER` / `PANEL_PASSWORD` → owner.  
Доп. люди — только через **Доступ**.

## Что ещё оставлять (принцип)

**Оставляем в панели только то, что смотрят глазами и редко крутят руками.**  
Меры (бан/мут/варн) — в Discord `/modpanel`, не дублируем кнопками в вебе.

| Нужно? | Что | Куда |
| --- | --- | --- |
| да | журнал / участник / варны / апелляции / демки / причины | mod |
| да | бот / модули / команды / антикраш / доступ | owner |
| позже, если надо | антирейд / antifake / guardian — **краткий статус** | owner |
| нет | экономика, темы, AI-чат панели, аналитика 90 дней, массовые действия, редактор каналов/ролей | — |

Чего нет специально: старое меню, раздутые права, демо-аккаунты.
