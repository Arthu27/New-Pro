# Страницы панели (ядро модерации)

Новая панель с нуля. Старый `web/` и его меню/права **не используются**.

## Для модераторов (mod+)

| Страница | URL | Зачем |
| --- | --- | --- |
| **Сегодня** | `/` | KPI за день + последние наказания (новые сверху) |
| **Журнал** | `/logs` | Все наказания: цель, мод, причина, срок |
| **Участник** | `/member` | Поиск по ID/нику → история мер |
| **Варны** | `/warns` | Список предупреждений |
| **Апелляции** | `/appeals` | Очередь апелляций |
| **Демки** | `/proofs` | Доказательства к наказаниям |
| **Причины** | `/reasons` | Причины наказаний + правила (для /modpanel) |

## Только владелец (owner) — бот

Модераторы этих страниц **не видят** и API им закрыт.

| Страница | URL | Зачем |
| --- | --- | --- |
| **Бот** | `/bot` | Онлайн, пинг, гильдии |
| **Модули** | `/modules` | Какие коги загружены |
| **Команды** | `/commands` | Список slash (обзор) |
| **Доступ** | `/access` | Кому выдан вход в панель и роль |

## Вход

| Страница | URL |
| --- | --- |
| **Вход** | `/login` |

Логин: `PANEL_USER` / `PANEL_PASSWORD` из `.env` (роль `owner`).  
Доп. люди — только через **Доступ** (файл `data/panel_access.json`, создаётся пустым).

## Чего нет специально

Аналитика, экономика, антирейд-UI, темы, AI-чат панели, массовые действия,
настройки каналов/ролей сервера — всё это убрано, чтобы права и поверхность
не раздувались. Управление мерами — через Discord `/modpanel`.
