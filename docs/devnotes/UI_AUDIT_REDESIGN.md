## 3. Что мешает редизайну

### 3.1. CSS и JS минифицированы, исходников нет — блокер номер один
Коммит `ace324d` сжал `style.css` 243→174 КБ и `app.js` 186→92 КБ по месту. Неминифицированной версии
в репозитории нет, сборщика тоже. Искать правило в 174 КБ одной строкой — так редизайн не делается.
Нужно вернуть читаемый источник: `web/static/src/style.css` плюс скрипт минификации, либо развернуть
`style.css` обратно (под gzip разница между 174 и 243 КБ — единицы килобайт).

### 3.2. Один компонент скопирован на 23 страницы
У каждой страницы свой префикс: `ac- am- an- at- au- bd- bs- dp- ff- gf- km- lb- lg- ms- mt- pf- rp- si- sl- sr- ss- tk- tv-`,
и у каждого своя панель, секция, подзаголовок, инпут, кнопка (`-panel -sec -sub -input -btn -save`).
В CSS это селектор-группы по 25 штук с одинаковым телом:

- `.ac-box, .ach-kpi, .am-panel, .an-card, .an-panel, …` — 25 селекторов, одни и те же свойства
- `.ac-input, .am-input, .an-input, …` — 25 селекторов
- `.ac-btn, .am-btn, .an-btn, …` — 25 селекторов

Карточка, форма и кнопка написаны примерно 23 раза. «Поменять все карточки» = 23 правки в разных местах.
Лечится одним набором компонентов (`.card`, `.field`, `.btn`), к которому подключаются страницы.

### 3.4. Пять страниц живут своей дизайн-системой
`login.html`, `register.html`, `welcome.html`, `public_apply.html`, `status_public.html` не наследуют
`base.html` и объявляют свой `:root`. У них фон `#05060a`, радиусы 20/12/9 px и градиент
`#4f46e5 → #6d28d9 → #7c3aed`, тогда как панель — фон `#0f1013`, радиусы 14/10/6 и градиент
`#4f46e5 → #4338ca`. Вход и главная выглядят как другой продукт.

### 3.5. Стили расползлись по шаблонам
- 72 блока `<style>` внутри шаблонов; в `chat.html` один такой блок на 776 строк
- 1273 атрибута `style="…"` прямо в разметке (рекордсмены: `appeals.html` 86, `mod_schedule.html` 70,
  `notifications.html` 68, `proofs.html` 59, `dashboard.html` 59)
- 168 уникальных hex-цветов в шаблонах, 712 вхождений. Топ: `#4f46e5` (35), `#7c3aed` (32),
  `#23a55d` (31), `#d97706` (28), `#22d3ee` (28), `#16a34a` (27)
- в самом `style.css` 58 уникальных hex мимо токенов

Последствие: пикер акцента перекрашивает только то, что ходит через `var(--ac)`.
Всё, что зашито в hex, останется прежнего цвета.

## 4. Что хорошо и что стоит сохранить

- Токены темы и переключатель светлая/тёмная без вспышки — сделано правильно
- Пикер акцента уже пересчитывает градиент и полупрозрачные варианты из одного hex — хороший фундамент
- Все 71 страница живые, падений нет
- Есть `prefers-reduced-motion`, skip-link, `:focus-visible`, aria-атрибуты, touch-цели 44px — доступность не с нуля
- Шрифтовая пара Inter + Unbounded + JetBrains Mono для цифр — нормальная основа
