===============================================

[Пользователь открывает тикет]
        │
        ▼
[AI приветствие]
        │
        ▼
[Пользователь излагает жалобу]
        │
        ▼
[AI: классификация + серьёзность]
        │
        ├─ вопрос ──────────────► [AI отвечает сам] ──► [закрытие]
        │
        ▼ жалоба
[AI: запрос доказательств]
        │
        ├─ пользователь присылает скриншоты/ссылки
        ├─ AI подтягивает удалённые сообщения из кэша
        │
        ▼
[AI: многосторонний анализ]
        │ проверка: обоюдные нарушения? провокация? подтасовка?
        ▼
[AI: резюме + тип решения + рекомендация меры]
        │ (учитывает историю штрафов → рецидив строже)
        ▼
[Staff: подтверждает / корректирует]
        │
        ▼
[Применение меры: warn / timeout / mute / kick / ban]
        │
        ├─ запись в data/ticket_penalties.json
        ├─ запись в логи модерации
        └─ DM пользователю о мере и причине
        ▼
[Тикет закрыт]
        │
        ▼
[Самообучение: удачные решения staff → FAQ-база]
[... 10 сообщений спустя ...]
[Новый тикет того же пользователя → AI видит историю]
