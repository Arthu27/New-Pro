# 🛡️ AI Moderator — Руководство

## 🎯 Сводка системы

AI-модератор работает внутри тикетов: принимает жалобу, запрашивает
доказательства, анализирует ситуацию (включая обе стороны конфликта),
выносит рекомендацию по наказанию и — с подтверждения персонала —
применяет меру.

## 🔄 Новый рабочий поток

### 1️⃣ Пользователь открывает тикет
Пишет жалобу своими словами. AI приветствует и берёт диалог на себя.

### 2️⃣ Пользователь излагает жалобу
AI определяет категорию и серьёзность. По жалобам обязательно
запрашивает доказательства — голословные обвинения не принимаются.

### 3️⃣ Пользователь загружает доказательства
Скриншоты, ссылки на сообщения, ID. Плюс AI автоматически подтягивает
удалённые сообщения сторон из кэша бота.

### 4️⃣ AI выносит решение
Резюме + тип решения + рекомендуемая мера с учётом:
- тяжести нарушения,
- истории штрафов пользователя (рецидив),
- многостороннего анализа (обоюдные нарушения).
Staff подтверждает или корректирует — финальное слово за человеком.

## 🎯 Возможности AI-модератора

### ✅ Умеет
- Классифицировать обращение и серьёзность.
- Запрашивать и собирать доказательства.
- Анализировать обе стороны конфликта.
- Учитывать историю нарушений (штрафы).
- Формировать резюме и рекомендацию наказания.
- Применять меру после подтверждения staff и логировать действие.

### ❌ Не умеет (осознанно)
- Наказывать без подтверждения персонала.
- Разбирать инциденты вне сервера (ЛС, другие серверы).
- Принимать решение по жалобе без доказательств.
- Отменять наказания, выданные старшим составом.

## 📊 Уровни серьёзности

| Уровень | Примеры | Рекомендуемая мера |
|---|---|---|
| Низкая | лёгкий спор, первый флуд | Предупреждение |
| Средняя | оскорбления, спам, рецидив мелкого | Тайм-аут / мут (часы) |
| Высокая | угрозы, NSFW, рейд-участие | Мут (дни) / кик |
| Критическая | доксинг, рейд-организация, угрозы жизни | Бан + доклад администрации |
