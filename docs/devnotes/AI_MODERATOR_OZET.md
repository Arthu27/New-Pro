# 🛡️ AI Moderator — Краткая сводка

## Что изменилось?

### Старая система ❌
- Жалоба сразу падала персоналу без структуры.
- Доказательства staff запрашивал вручную каждый раз.
- Решение принималось «на глаз», без учёта истории.

### Новая система ✅
- AI сам принимает жалобу и запрашивает доказательства.
- Анализ обеих сторон + удалённые сообщения из кэша.
- Рекомендация с учётом истории штрафов и рецидива.
- Staff только подтверждает решение — экономия времени.

## 🎯 Новые возможности

### 1. Запрос доказательств
AI не даёт эскалировать голословную жалобу: сначала скриншоты,
ссылки, ID — и только потом разбор.

### 2. Анализ
Резюме инцидента, классификация нарушения, уровень серьёзности,
обнаружение обоюдных нарушений и ложных жалоб.

### 3. Вынос решения
Тип решения (`single_offense` / `mutual_violation` / `provocation` /
`false_report`) + рекомендуемая мера по матрице серьёзности.

### 4. Применение наказания
После подтверждения staff: предупреждение / тайм-аут / мут / кик / бан,
запись в штрафы и в логи модерации.

## 📋 Рабочий поток (кратко)

```
жалоба → AI: запрос доказательств → доказательства
      → AI: анализ + резюме + рекомендация
      → staff: подтверждение
      → применение меры + запись в историю
```
