# Система AI-тикетов — Обзор

Комплексная система тикетов с AI-поддержкой первого уровня:
AI приветствует пользователя, ведёт диалог, категоризирует обращение,
решает типовые вопросы сам и эскалирует сложные случаи персоналу.

## 🎯 Особенности

### 1. Автоматическое AI-приветствие
Как только тикет открыт, AI приветствует пользователя по имени,
объясняет, чем может помочь, и задаёт уточняющий вопрос.

### 2. Умный диалог
- Контекст диалога сохраняется в течение всей сессии тикета.
- AI отвечает на типовые вопросы (правила, роли, команды, настройки).
- Много-модельная схема: Mistral Small — простые вопросы,
  Mistral Medium — поддержка, Mistral Large — сложные жалобы.
- Работает локальный fallback (Ollama), если внешний API недоступен.

### 3. Автоматическое направление (эскалация)
AI классифицирует обращение и сам решает:
- **решить самостоятельно** — типовые вопросы;
- **эскалировать персоналу** — жалобы с обоюдными нарушениями,
  апелляции, технические проблемы бота, конфликты.

### 4. Контроль персонала
- Staff берёт тикет в работу одной кнопкой, AI переходит в режим ассистента.
- AI подсказывает модераторам краткое резюме ситуации и рекомендации.
- Все действия (AI и staff) логируются для аудита.

### 5. Интеграция с веб-панелью
- `/ai-tickets` — список и управление AI-тикетами.
- `/ai-ticket-stats` — аналитика: категории, эскалации, среднее время ответа.

## 📋 Команды

### Пользователь
- Кнопка «Открыть тикет» в панели — создание тикета.
- Внутри тикета: просто писать сообщения — AI отвечает автоматически.

### Администратор
- `/ticket-ai-stats` — статистика AI-тикетов сервера.
- `/ticket-ai-toggle` — включить/выключить AI-поддержку в тикетах.
- `/ticket-force-escalate` — принудительно передать тикет персоналу.

## 🔧 Технические детали

### Файлы
- `cogs/ticket.py` — основной cog тикетов + AI-логика диалога.
- `services/advanced_ticket_features.py` — расширенные функции (штрафы, состояние).
- `services/rate_limiter.py` — защита от спама/флуда тикетами.
- `web/routes_extra.py` + `web/templates/ai_tickets*.html` — веб-интерфейс.

### Данные
- `data/ai_tickets_{guild_id}.json` — состояние AI-тикетов сервера.
- `data/ticket_penalties.json` — штрафы (по системе многосторонних нарушений).

### AI-модель
- Провайдеры: Mistral API (основной), OpenAI/OpenRouter/DeepSeek (альтернативы),
  Ollama (локальный fallback, ключ не нужен).
- Настройка в `.env`: `MISTRAL_API_KEY`, `OLLAMA_URL`, `AI_MODEL` и т.д.
