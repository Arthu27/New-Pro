# AI Ticket Sistemi — Полный список функций

## 🎯 Обзор

Полный перечень возможностей, добавленных в AI-тикет систему.
Разбито по приоритетам: критичные → важные → продвинутые.

## ✅ Добавленные функции

### 🔥 Tier 1: Критичные (ЗАВЕРШЕНО)

1. **AI-приветствие при открытии тикета** — мгновенное приветствие
   по имени пользователя с объяснением возможностей.

2. **Контекстный диалог** — AI помнит всю переписку тикета и отвечает
   с учётом предыстории.

3. **Умная категоризация** — жалоба / вопрос / техника / апелляция / другое
   (см. `AI_TICKET_KATEGORIZE.md`).

4. **Автозапрос доказательств** — по жалобам AI сам просит скриншоты,
   ссылки на сообщения и детали.

5. **Эскалация персоналу** — автоматическая и принудительная
   (`/ticket-force-escalate`), с резюме ситуации для staff.

6. **Кэш удалённых сообщений** — удалённые нарушителем сообщения
   подтягиваются из кэша как доказательства:
   ```
   удалённое сообщение → кэш → резюме для staff
   ```

### ⚡ Tier 2: Важные (ЗАВЕРШЕНО)

7. **Многосторонний анализ нарушений** — при обоюдном конфликте AI
   оценивает роль каждой стороны (см. `AI_TICKET_MULTI_PARTY_SYSTEM.md`).

8. **Система штрафов (penalty)** — повторные нарушения повышают
   серьёзность рекомендуемого наказания.

### 🎯 Tier 3: Продвинутые (ЧАСТИЧНО)

9. **Самообучение FAQ** — успешные ответы staff сохраняются в базу
   знаний (`/faq-learn`, `/faq-list`) и используются в новых тикетах.

10. **Рекомендации staff** — AI предлагает модератору варианты решения
    с учётом истории нарушений пользователя.

## 📊 Структуры данных

### 1. Файл штрафов (`data/ticket_penalties.json`)
По каждому пользователю: количество инцидентов, типы нарушений,
дата последнего, эскалационный множитель.

### 2. Состояние тикетов (`data/ai_tickets_{guild_id}.json`)
По каждому тикету: категория, статус (AI/staff), история диалога,
собранные доказательства, резюме для персонала.

## 🔄 Рабочие потоки

### Поток 1: Обоюдный мут
Конфликт двух участников → AI анализирует обе стороны →
штраф распределяется пропорционально вине →
рекомендация staff: мут обоим (разные сроки) или предупреждения.

### Поток 2: Апелляция
Наказанный открывает тикет → категория `апелляция` →
AI собирает доводы → резюме + история нарушений →
решение принимает старший состав.

### Поток 3: Доп. доказательства
Staff (или AI в диалоге) запросил доказательства →
пользователь загружает скриншоты/ссылки →
AI прикрепляет их к резюме тикета автоматически.
