AI TICKET SİSTEMİ — ПОТОК РАБОТЫ (текстовая схема)
=================================================

1. ОТКРЫТИЕ
   [Пользователь] → кнопка «Открыть тикет»
   [Rate limiter]  → проверка лимита (анти-спам)
   [Бот]           → создаёт приватный канал тикета
   [AI]            → приветствие + вопрос о сути обращения

2. КАТЕГОРИЗАЦИЯ
   [Пользователь] → пишет суть проблемы
   [AI]           → классификация: жалоба / вопрос / техника / апелляция / другое
                  → категория сохраняется в состоянии тикета

3. ДИАЛОГ
   вопрос    → AI отвечает сам (FAQ, правила, команды)
   жалоба    → AI запрашивает доказательства (скрины, ссылки)
               + подтягивает удалённые сообщения из кэша
   техника   → AI собирает шаги воспроизведения
   апелляция → AI собирает доводы + историю нарушений

4. РЕШЕНИЕ / ЭСКАЛАЦИЯ
   AI решает сам          → пользователь закрывает тикет
   Требуется staff        → эскалация: тег роли + резюме ситуации
   Принудительно          → /ticket-force-escalate

5. РАБОТА STAFF
   [Staff] → берёт тикет (AI переходит в режим ассистента)
   [AI]    → резюме + рекомендация (включая многосторонний анализ)
   [Staff] → выносит решение → наказание / отклонение

6. ЗАКРЫТИЕ
   [Тикет закрыт]
   [Самообучение] → успешные решения → база знаний FAQ
   [Штрафы]       → запись инцидента в data/ticket_penalties.json

   [... 10 сообщений спустя в новом тикете того же пользователя ...]
   [AI] видит историю штрафов → учитывает рецидив при рекомендации
