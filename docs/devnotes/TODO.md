# Добавленные системы 🚀

Историческая сводка завершённых модулей бота.
(Актуальный список модулей — каталог `cogs/`.)

## 1. Система уровней 📊
- Начисление XP за сообщения, повышение уровня, уведомления.
- Карточка уровня и таблица лидеров.
- Команды: `/уровень [@участник]`, `/лидеры`.

## 2. Система опросов 📊
- Создание опросов с автоматическими реакциями для голосования.
- Подведение итогов и закрытие опроса.
- Команды: создание через slash-команду, итоги — по ID опроса.

## 3. Роли по реакциям 🎭
- Автоматическая выдача/снятие ролей по реакциям на сообщении.
- Поддержка нескольких реакций-ролей, интеграция с веб-панелью.
- Модуль: `cogs/reaction_roles_cog.py`.

## 4. Welcome/Goodbye 👋
- Настраиваемые сообщения при входе/выходе участников.
- Embed и текст, плейсхолдеры (`{user}`, `{server}` и др.), DM-приветствие.
- Модуль: `cogs/welcome_cog.py`, настройка в веб-панели (welcome editor).

## 5. Пользовательские команды 📝
- Создание своих команд (триггер → ответ) с плейсхолдерами.
- Статистика использования, поддержка embed.
- Управление из веб-панели (раздел пользовательских команд).

## 6. Starboard ⭐
- Автопост лучших сообщений по реакциям (звёзды) в отдельный канал.
- Настраиваемый порог звёзд, собственный эмодзи.
- Страница настройки: веб-панель → Starboard.

## 7. Система предложений 💡
- Подача предложений через slash-команду, голосование 👍👎.
- Принятие/отклонение персоналом, DM-уведомление автору.
- Страница: веб-панель → Предложения.

## 8. Розыгрыши 🎁 (ЗАВЕРШЕНО — 100%)
- Создание розыгрышей (веб-панель + бот), участие кнопкой.
- Автовыбор победителя, перевыбор (reroll), DM победителю.
- Модуль: `cogs/giveaway.py`, страница в панели.
