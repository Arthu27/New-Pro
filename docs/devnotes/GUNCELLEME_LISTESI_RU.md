## 💰 1. НОВАЯ ПРОФЕССИОНАЛЬНАЯ ЭКОНОМИЧЕСКАЯ СИСТЕМА

### 🏦 Банк (новое)
- `!bank` — ваш счёт, процент по вкладу, лимит
- `!deposit` / `!withdraw` — положить / снять деньги
- `!interest` — **проценты по вкладу** (раз в 6 часов)
- `!bankup` — **улучшение банка** (растёт лимит и процент)

### 👨💼 Профессии (новое, 10 профессий)
- `!job программист / полицейский / доктор / фермер / рыбак / шахтёр / таксист / курьер / повар / стример`
- `!jobs` — список всех профессий
- `!work` — работать по профессии
  - зарплата, **критический успех**, **уровень + опыт**, **случайные события** (бонус/потеря)

### 📅 Ежедневные и еженедельные награды
- `!daily` — теперь со **стриком** (серия дней), чем дольше серия — тем больше бонус
- `!weekly` — еженедельная награда

### 🛒 Магазин и инвентарь
- `!shop` — красивый магазин с **меню-выбором** (магазин / инвентарь / баланс)
- `!buy` — 14+ предметов с **редкостями** (обычный → божественный)
- `!inventory` — ваш инвентарь
- `!sell` — продать предмет
- `!use` — использовать предмет

### 🐾 Питомцы (новое)
- `!buy кошка / собака / лиса / волк / дракон`
- `!pets` — ваши питомцы
- `!use дракон` — выбрать активного питомца → **бонус к работе** (+10% до +50%)

### 🎰 Казино (новое)
- `!slots` — игровые автоматы (джекпот!)
- `!casino-coinflip 100 орел` — монетка
- `!casino-dice 100 higher` — кость

### 📦 Кейсы (новое)
- `!kasa обычный / редкий / эпический / легендарный` — откройте кейс и получите предмет или деньги

### 📈 Биржа (новое)
- `!stock view` — текущие цены (Apple, Discord, AI Corp, Crypto)
- `!stock buy apple 5` — купить акции
- `!stock sell apple 2` — продать акции

### 💸 Торговля, история, лидеры
