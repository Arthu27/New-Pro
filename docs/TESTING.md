# Тестирование Hakumo (MOEBIUS)

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-test.txt
.venv/bin/python scripts/run_tests.py
```

Прогон — без токена Discord, без сети, на временной SQLite-базе: каждый
набор изолирует себя (`tempfile.mkdtemp` + `DB_PATH`).

## CI

`docs/github-actions-tests.yml` — готовый workflow. Скопируйте его в
`.github/workflows/tests.yml` (у бота-токена Arena нет scope `workflows`,
поэтому копирование — за вами), и GitHub Actions будет гонять регрессию
сам.

## Правило для новой фичи

1. Логика — чистыми функциями наверху модуля.
2. Тест `tests/test_<фича>.py` по контракту из [`tests/README.md`](../tests/README.md).
3. Прогон всей регрессии — зелёный.
4. Счётчик в корневом README поднят до фактического.

## Что сторожат глобальные тесты

- обрезанные слова/турецкие вкрапления в сообщениях пользователю;
- `utcnow()` и naive-метки времени (панель врёт «4 часа назад»);
- молчаливые `except: pass/continue`;
- env-ключи кода без документирования в `.env.example`;
- декоративные эмодзи в шаблонах панели;
- соответствие меню панели режиму модулей (MOD_ONLY).
