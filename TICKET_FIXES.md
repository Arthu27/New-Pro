# Тикет-система — Исправления

## 🐛 Исправленные проблемы

### Проблема 1: Ошибка при открытии тикета ❌→✅

**Симптом:** при нажатии кнопки «Открыть тикет» Discord показывал
«Приложение не отвечает».

**Причина:** Discord требует ответ на interaction в течение **3 секунд**.
Бот сначала создавал канал (долгий запрос к API) и только потом отвечал.

**Решение — правильный порядок:**

```python
# 1. СНАЧАЛА отвечаем на interaction (до 3 секунд)
await interaction.response.defer(ephemeral=True)

# 2. ПОТОМ создаём канал тикета
channel = await guild.create_text_channel(...)

# 3. В КОНЦЕ отправляем результат через followup
await interaction.followup.send(f"Тикет создан: {channel.mention}")
```

### Проблема 2: AI не отвечает в тикете ❌→✅

**Симптом:** пользователь пишет, AI молчит.

**Причины и исправления:**
1. Listener не проверял, что сообщение из тикет-канала —
   добавлен фильтр по префиксу/категории канала.
2. Отсутствовал AI-ключ — добавлена явная проверка `MISTRAL_API_KEY`
   с понятным сообщением в логах и fallback на Ollama.
3. Rate limiter молча отсекал сообщения — теперь присылает
   уведомление «подождите N сек.».

## 🎯 Тестовые сценарии (регрессия)

### Тест 1: Открытие тикета
Нажать кнопку → за ≤ 3 сек. ephemeral-подтверждение → канал создан →
ссылка-приглашение пришла followup'ом. ✅

### Тест 2: Ответ AI
Написать в новом тикете «привет» → AI отвечает ≤ 10 сек.
В логах нет ошибок ключа/лимитера. ✅
