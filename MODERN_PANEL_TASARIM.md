# 🎨 Современный дизайн панели — Статистика AI-тикетов

Дизайн-концепция страницы `web/templates/ai_ticket_stats.html`.

## ✨ Особенности дизайна

### **Glassmorphism**
Полупрозрачные карточки с размытием фона (`backdrop-filter: blur`),
тонкие светлые границы, многослойная глубина.

### **Градиентный фон**
Тёмная тема: глубокий синий → фиолетовый градиент страницы,
контрастные акценты на элементах данных.

### **Микро-взаимодействия**
- Плавный подъём карточки при наведении (`transform: translateY`).
- Анимированные счётчики (числа «набегают» при загрузке).
- Мягкие переходы по `transition: 200ms ease`.

### **Типографика**
- Заголовки: крупный жирный шрифт, повышенный контраст.
- Числа-метрики: моноширинный акцент для читаемости.
- Вторичный текст: приглушённый серый.

### **Цветовая палитра**
| Роль | Цвет |
|---|---|
| Основной акцент | фиолетово-синий градиент |
| Успех (решено AI) | зелёный |
| Эскалации | янтарный |
| Критичные | красный |
| Фон карточек | белое стекло 6–10% |

## 🎯 Принципы дизайна

### 1. Осознанный минимализм
Только значимые метрики: открыто/закрыто, эскалации, категории,
среднее время ответа. Никаких декоративных элементов без функции.

### 2. Визуальная иерархия
Сверху вниз: сводные KPI-карточки → графики по категориям →
таблица последних тикетов. Взгляд движется от общего к деталям.

### 3. Доступность
Контраст текста ≥ WCAG AA, статусы дублируются
иконкой + цветом + текстом (не только цветом).

## 📐 Структура страницы
1. Шапка: заголовок + фильтр периода.
2. Ряд KPI-карточек (4 шт., стекло).
3. Графики: распределение по категориям, динамика эскалаций.
4. Таблица последних тикетов с цветовой маркировкой статуса.
