# config/ — примеры конфигураций

Образцы конфигов, которые можно скопировать и адаптировать. Живые настройки
проекта лежат не здесь: секреты и флаги — в `.env` (шаблон —
[`.env.example`](../.env.example) в корне), пользовательские данные — в
`data/` (SQLite + JSON).

| Файл | Зачем |
| --- | --- |
| `ticket_config_example.json` | Образец конфигурации тикет-системы: категории, роли поддержки, лимиты. Подсматривайте структуру при настройке через панель («Тикеты → Настройки»). |
