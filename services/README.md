# services/ — сервисный слой

Библиотеки общей логики: не коги и не роуты — чистые служебные модули,
которые импортируют и бот (`cogs/`), и панель (`web/routes/`).

## Выдающиеся жители

| Модуль | Назначение |
| --- | --- |
| `text_format.py` | **Русское форматирование**: склонения (`plural_ru`), длительности (`fmt_seconds`, `parse_duration`, `parse_deadline`, `rel_time`). Единственная точка «ч/мин/сек» в проекте. |
| `panel_menu.py` | Сайдбар панели: группы/страницы, видимость по ролям, **карта `PAGE_COGS`** — какие страницы обслуживаются какими когами (гашение пунктов в MOD_ONLY). |
| `notification_dispatcher.py` | Шина уведомлений панели/Discord (`notify_event`). |
| `rate_limiter.py` | Антиспам-ограничитель API панели. |
| `database.py` | Низкоуровневый SQLite-слой панели. |
| `ticket_system.py` | Ядро тикетов для панели и бота. |
| `feature_flags.py` | Фиче-флаги (вкл/выкл фич без рестарта). |
| `permission_acl.py` | Матрица прав команд (страница «Доступ к командам»). |
| `backup.py` | Автобэкапы `data/` с ротацией. |
| `panel_todo.py`, `web_dashboard.py` | Задачи и виджеты панели. |

## Правила

1. Сервис — **без побочных эффектов при импорте** (никаких коннектов,
   создания папок на верхнем уровне модуля; путь БД — через `Config.DB_PATH`).
2. Сетевые вызовы, тяжёлые импорты — внутри функций.
3. Чистое ядро — чистое: форматирование и решения тестируются тремя
   строками `os.chdir(tempfile)+sys.path+import`.
4. Ноль молчаливых except, только aware UTC — сторожа те же, что у когов.
