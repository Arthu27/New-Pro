Роли наказаний

Какую роль бот выдаёт за каждое наказание и каждый уровень предупреждений. Выбор — только из списка ролей сервера: никаких ID вручную. Сохранение одним нажатием — бот применяет сразу.

Настройка: Админ
Часть выбранных ролей удалена с сервера — их селекты помечены. Выберите новую роль или «не выдавать».

Роли за наказания

Что бот делает при наказании. Если роль не выбрана — работает старое поведение (мут чата — таймаутом, «бан» — изоляцией каналов). Временные роли бот снимает сам по сроку.

Наказания без роли — тоже наглядно

Для каждого наказания — всё на своей карточке. Где роль не нужна технически (таймаут Discord, кик, разбан) — карточка это объясняет, без «тупых» сюрпризов.

Действия за варны (мут / войс-мут / кик / бан)

Что бот делает при N предупреждениях — настраивается в одном месте, на странице «Лестница наказаний» (там же — наглядная картинка-лестница и проверка «что будет участнику»). Здесь дублирующего выбора нет, чтобы расхождений не возникало.

Мут чата и бан ролью (карточки выше) выигрывают у нативного таймаута/бана — применятся они, если назначены. Войс-мут — отдельное действие (глушит только микрофон), выбирается в лестнице отдельно от чат-мута.

Роли уровней предупреждений

Сколько уровней — столько карточек, вы решаете сами: добавьте уровень (например «3 предупреждения») и выберите роль. Участник с N предупреждениями получает роль ближайшего уровня не выше N, роль предыдущего уровня снимается автоматически, дублей не бывает. Варн снят — уровень падает, роль пересчитывается. Пустой селект = без роли за этот уровень.
Сохраняются только роли (виды наказаний и уровни варнов). Что бот делает при N варнах — на странице «Лестница наказаний».
