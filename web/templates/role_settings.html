Роли наказаний

Какую роль бот выдаёт за каждое наказание и каждый уровень предупреждений. Выбор — только из списка ролей сервера: никаких ID вручную. Сохранение одним нажатием — бот применяет сразу.

Настройка: Админ
Бот офлайн — список ролей сервера недоступен, сохранять нельзя. Настройки вернутся, когда бот включится.
Часть выбранных ролей удалена с сервера — их селекты помечены. Выберите новую роль или «не выдавать».

Роли за наказания

Что бот делает при наказании. Если роль не выбрана — работает старое поведение (мут чата — таймаутом, «бан» — изоляцией каналов). Временные роли бот снимает сам по сроку.

Роли уровней предупреждений

Участник с N предупреждениями получает роль ближайшего уровня не выше N — роль предыдущего уровня снимается автоматически, дублей не бывает. Варн снят — уровень падает, роль пересчитывается. Пустой селект = без роли за этот уровень.
Применяется к обоим разделам разом. Значения общие с блоком «Роли наказаний» в настройках модерации.
