На грани авто-наказания

CSV варнов
Участники с варнами, которым до следующего авто-наказания (пороги со страницы «Варны») не хватает один-два предупреждения.

Амнистия

Обнуляет все варны участника. Запись попадает в журнал — любую амнистию можно откатить, пока после неё не появились новые варны.

Варн из панели

Запись попадает в тот же журнал варнов, что читает бот. Важно: авто-наказание по порогам бот применяет только к варнам, выданным его командой — панельная запись ведёт учёт.
Выдавать и снимать варны из панели могут администраторы.

Последние действия

Свежие кары и снятия из журнала модерации — пульс команды за последние дни.

Журнал панели

Каждая операция руками (варн, амнистия, причины) записывается с именем — чтобы в команде всё было прозрачно.

Радар истечений

CSV
Временные наказания, которые просрочены или закончатся в ближайшие трое суток. Бот сам снимает их по таймеру — список нужен для контроля.

Быстрые причины

Шаблоны причин, которые модератор вставляет одним кликом при выдаче наказания. Общие для команды, добавляет администратор.
До 20 причин на каждый тип; длина — до 120 символов.
