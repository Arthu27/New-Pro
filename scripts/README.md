# scripts/ — служебные скрипты

| Скрипт | Что делает |
| --- | --- |
| `run_tests.py` | Прогон всей регрессии `tests/`: сводка «наборов/проверок/проблем», код выхода для CI. `-v` — хвост вывода упавших. |
| `check_files.py` | Статическая проверка «дружбы» файлов: порты (5001) во всех местах, origin-политика `127.0.0.1` (без `localhost` = IPv6 `::1`), вызовы `main.py` ↔ `services/named_tunnel.py`, `setup_panel_tunnel.bat` ↔ Python, URL ↔ живые маршруты Flask, `.env.example` ↔ код, конфиги туннеля на диске, синтаксис. Ничего не запускает и не меняет; на VDS запускай после обновления. |
| `check_health.py` | Глубокий аудит «всё идеально, даже мелочи»: прогон check_files + лимиты Discord (описания ≤ 100 симв., имена ≤ 32, слэш ≤ 100, меню ≤ 5, дубли), setup() у каждого кога, шаблоны/статика/роли, защита КАЖДОГО роута панели (`@login_required` или осознанный белый список), валидность JSON, зависимости ↔ requirements, гигиена git (.env не в репо), тесты, живая панель. |
| `check_connection.py` | Живая проверка соединения «бот ↔ веб-панель»: `.env`, `/health` (панель видит бота), WebSocket-порт 8765, файлы-мосты `data/*.json`, маршруты каналов. Запускать при работающем боте. |
| `demo_panel.py` | Демо-превью веб-панели без Discord-бота: фейковый сервер, засев логов/демок/голосовой статистики, вход через `/demo-login` на `http://0.0.0.0:8090`. |
| `gen_module_docs.py` | Пересобирает [`docs/MODULES.md`](../docs/MODULES.md) из docstring-ов когов (`--write` — записать файл). |

Запускать из корня репозитория: `python3 scripts/<имя>.py`.
