# scripts/ — служебные скрипты

| Скрипт | Что делает |
| --- | --- |
| `run_tests.py` | Прогон всей регрессии `tests/`: сводка «наборов/проверок/проблем», код выхода для CI. `-v` — хвост вывода упавших. |
| `demo_panel.py` | Демо-превью веб-панели без Discord-бота: фейковый сервер, засев логов/демок/голосовой статистики, вход через `/demo-login` на `http://0.0.0.0:8090`. |
| `gen_module_docs.py` | Пересобирает [`docs/MODULES.md`](../docs/MODULES.md) из docstring-ов когов (`--write` — записать файл). |

Запускать из корня репозитория: `python3 scripts/<имя>.py`.
